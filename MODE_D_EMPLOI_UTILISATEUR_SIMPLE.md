# MODE D'EMPLOI - Bibliothèque Scolasticat Père Piariste
**Public :** Visiteurs et Membres (utilisateurs simples)  
**Site en ligne :** https://bibliotheque-a4sw.onrender.com/  
**Version :** Octobre 2026

## 1. Description du projet

La Bibliothèque Scolasticat Père Piariste est une application web permettant de gérer le fonds documentaire de la Congrégation. Elle offre aux membres un accès au catalogue en ligne, la possibilité de s'inscrire, de suivre ses emprunts, d'entrer en liste d'attente et de contacter l'administration en cas de besoin.

## 2. Objectifs

- Mettre à disposition du public le catalogue des ouvrages
- Faciliter l'enregistrement des emprunts/retours par le bibliothécaire
- Informer les membres de leurs échéances
- Permettre la réservation lorsqu'un livre est indisponible
- Assurer le suivi des demandes via une messagerie

## 3. Accès au site

Ouvrez votre navigateur et allez sur : **https://bibliotheque-a4sw.onrender.com/**

Le site est optimisé pour **ordinateur, tablette et smartphone**.

## 4. Utilisation pour un utilisateur simple (visiteur/membre)

### 4.1 Consulter le catalogue
1. Sur la page d'accueil, vous voyez la liste des ouvrages
2. Utilisez la barre de recherche pour trouver un livre par titre, auteur ou mot-clé
3. Filtrez par catégorie ou par disponibilité (« Disponibles uniquement »)
4. Cliquez sur un livre pour ouvrir sa fiche détaillée

### 4.2 Obtenir un résumé IA d'un livre
Sur la **fiche détaillée** d'un ouvrage (accessible en cliquant sur le livre) :
1. Descendez jusqu'à la rubrique **« Résumé »**
2. Cliquez sur **« Résumé IA »**
3. Un résumé généré automatiquement par l'intelligence artificielle s'affiche en quelques secondes
4. Ce bouton est accessible à **tout visiteur**, même non connecté

*Remarque : Si aucun résumé n'est disponible dans la base, l'IA se base sur le titre et l'auteur pour proposer une présentation.*

### 4.3 Créer un compte / Se connecter
1. Cliquez sur **« Se connecter »** en haut à droite
2. **Nouveau membre ?** Cliquez sur « Créer un compte » pour vous inscrire (nom, prénom, email, mot de passe)
3. Après inscription, connectez-vous avec vos identifiants
4. En cas d'oubli, utilisez « Mot de passe oublié »

### 4.4 Mes emprunts (après connexion)
Dans le menu en haut → **« Mes emprunts »** :
- **En cours** : Livres actuellement empruntés avec date d'emprunt et date de retour
- **Historique** : Anciens emprunts déjà rendus
- **Bannière de rappel** : Si vous avez un livre à rendre, une alerte apparaît en haut (orange = bientôt dû, rouge = en retard)

### 4.5 Liste d'attente (réservations)
Si un livre est **« Emprunté »** (indisponible) :
1. Ouvrez sa fiche
2. Cliquez sur **« S'inscrire en liste d'attente »**
3. Allez dans **« Mes emprunts » → « Mes réservations »**
4. Vous verrez votre rang exact : **« Vous êtes n°X sur Y dans la liste d'attente »**
5. Quand c'est votre tour : **« C'est votre tour ! Vous pouvez venir emprunter ce livre. »**

### 4.6 Contacter l'administration
En bas de chaque page, cliquez sur **« Contacter l'administration »** dans le pied de page.
1. Remplissez : Nom, Prénom, Email, Téléphone (facultatif), Sujet, Message
2. Cliquez sur **« Envoyer le message »**
3. Un message de confirmation s'affiche. L'administration recevra votre demande directement dans son espace.

### 4.7 Changer de thème (clair/sombre)
En haut de la page (barre de navigation), cliquez sur l'icône **Lune/Soleil** pour basculer entre mode sombre et mode clair. Votre choix est mémorisé automatiquement.

## 5. Conseils pratiques
- Utilisez un navigateur à jour (Chrome, Firefox, Edge, Safari)
- Sur téléphone, le menu se replie automatiquement
- Scannez un **QR code** collé sur un livre : il vous amènera directement à la fiche de ce livre

**Besoin d'aide ?** Utilisez le formulaire « Contacter l'administration » depuis le pied de page.
